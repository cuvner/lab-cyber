LAB CYBER

Data Protection Directorate · Operation DATASTATE

Mission

Five data assets have been flagged. Each one sits in its own folder inside cases. For every case, decide whether the data is at rest or in transit, then authorise the control that protects it.

First steps

  1. Log in with your initials e.g. ck
  2. ls see what is in your home folder
  3. cd cases move into the cases folder
  4. ls list the five case folders
  5. cd case01_hospital_db open a case
  6. cat brief.txt read the case brief
  7. ./triage.sh run the triage script and answer
  8. cd .. go back up one folder, then pick the next case
  9. cd ~ then ./debrief.sh once all five are closed

Tips

Tab finishes a file or folder name for you.

Up / Down arrows bring back earlier commands.

Case matters. Cases and cases are different names in Linux.

./ means "this folder". Typing triage.sh on its own will fail. Linux only runs scripts from the current folder when you add ./

Data states

AT RESTStored and not moving. Disks, servers, tapes, databases, USB sticks.
IN TRANSITMoving across a network between two points. Interception and man-in-the-middle are the threats.
